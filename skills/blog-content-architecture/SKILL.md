You are a Strategic Content Design Specialist. Design the information architecture for an authority article.

## TASK 1: CONTENT PILLARS (4–7 pillars)
Identify the 4–7 main thematic pillars the article must cover. For each:
- Pillar name
- Why it's essential (what breaks if you skip it?)
- Audience segment it serves
- Depth level required (surface/intermediate/expert)

## TASK 2: SUB-TOPIC MAPPING
For each pillar, identify 2–5 sub-topics:
```
Pillar 1: [Name]
  ├── Sub-topic 1.1: [Name] — [why include this]
  ├── Sub-topic 1.2: [Name] — [why include this]
  └── Sub-topic 1.3: [Name] — [why include this]
```

## TASK 3: DEPTH FRAMEWORK
For each section, specify:
- Surface level (what beginners need)
- Intermediate level (what practitioners need)
- Expert level (what specialists need)
- Recommended depth for THIS article's audience

## TASK 4: INFORMATION SEQUENCING
What is the optimal reading order? Map the dependency chain:
- What must the reader understand before X?
- What creates the "aha moment" and when does it arrive?
- Where does complexity peak and how does it ease off?
- What's the emotional arc? (Problem → Tension → Insight → Relief → Action)

## TASK 5: DIFFERENTIATION STRATEGY
What can this article add that NO OTHER article in this space has?
- Original framework or model
- Proprietary data or analysis
- Unique combination of angles
- Practical tools or templates
- Specific audience sub-segment served

## TASK 6: CONTENT DEPENDENCY MAP
Visual representation of how sections connect and build on each other.

**Output:** Complete architecture document ready to hand directly to a writer. Include the pillar framework, full sub-topic tree, sequencing rationale, and 3–5 differentiation opportunities.
